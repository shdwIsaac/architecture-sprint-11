Роадмап
Этап 1: Обновление DWH
Длительность: 3 месяца
Результат: Перевод DWH на ClickHouse
Ответственные: DevOps команда, DBA
Ресурсы: Серверное оборудование, лицензии
Обоснование: Улучшение производительности и безопасности базы данных.

Этап 2: Внедрение CI/CD
Длительность: 2 месяца
Результат: Настроенные процессы CI/CD для всех новых проектов
Ответственные: DevOps команда
Ресурсы: GitLab CI
Обоснование: Ускорение развертывания и улучшение качества кода.

Этап 3: Модернизация интеграционного слоя
Длительность: 4 месяца
Результат: Замена Apache Camel на Kafka или RabbitMQ перенос логики в новые собственные решения.
Ответственные: Архитекторы, разработчики интеграционных решений, DevOps команда
Ресурсы: Лицензии, обучение команды
Обоснование: Повышение надежности и производительности обмена данными.

Этап 4: Усиление безопасности
Длительность: 3 месяца.
Результат: Внедрение ABAC, шифрование данных, аудит доступа.
Ответственные: DevOps команда, специалисты по безопасности.
Ресурсы: Инструменты для управления доступом, обучение персонала.
Обоснование: Усиление безопасности критично для работы с медицинскими и персональными данными.


Текущий технический радар
Используется (Core):
Хранилище данных: Microsoft SQL Server 2008 (DWH).
Бизнес-аналитика: Power BI.
Интеграция: Apache Camel.
ИИ-сервисы: Python.
Финтех: Golang, Java.
Интерфейс для операторов: Power Builder.

На подходе (Adopt):
DWH: Миграция на хранилище данных Clickhouse.
Интеграция: Замена Apache Camel на Kafka или RabbitMQ.
Бизнес-аналитика: Расширение BI-решений.
Микросервисы: Внедрение микросервисной архитектуры с использованием Docker и Kubernetes.

Эксперименты (Trial):
Data Lake: Использование хранилищ данных для работы с неструктурированными данными.
CI/CD: Оптимизация процессов с использованием GitLab CI.
Система мониторинга: Внедрение Prometheus и Grafana для наблюдения за микросервисами и инфраструктурой.

Исследование (Assess):
Управление доступом: ABAC для усиления безопасности.
AI-аналитика: Использование инструментов AutoML для упрощения создания моделей.
Интеграция данных: Исследование возможностей iPaaS для сложных сценариев интеграции.
